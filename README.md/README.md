## Getting Started

### Prerequisites

Make sure you have the Dart SDK installed on your computer.

- [Install Dart SDK](https://dart.dev/get-dart)

Verify your installation:

```bash
dart --version
```

### Run a Dart File

1. Clone the repository:

```bash
git clone https://github.com/dmnaimrahman/dart.practice.git
```

2. Navigate to the project directory:

```bash
cd dart.practice
```

3. Run any Dart file:

```bash
dart run "Practice 1/problem1.dart"
```

You can replace the file path with any Dart file you want to execute.
